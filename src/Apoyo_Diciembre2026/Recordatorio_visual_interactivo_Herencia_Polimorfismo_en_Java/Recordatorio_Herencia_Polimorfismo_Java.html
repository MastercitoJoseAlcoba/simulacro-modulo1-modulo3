Herencia y polimorfismo, paso a paso

Entendé qué hereda una clase, qué método se ejecuta y por qué.

1. Recordatorio visual

Herencia

class Perro extends Animal

Perro es un subtipo de Animal. Hereda los miembros accesibles; los constructores no se heredan.
Polimorfismo

Animal a = new Perro();

El tipo declarado controla qué métodos son accesibles. El tipo real determina qué implementación sobrescrita de un método de instancia se ejecuta.

5. Métodos y palabras clave
JavaInterpretación
extendsHereda de una clase (una sola clase padre directa).
super(...)Invoca el constructor de la clase padre.
super.metodo()Invoca la implementación de la clase padre.
@OverrideComprueba que un método sobrescribe o implementa otro.
abstractClase no instanciable directamente; método abstracto sin cuerpo.
implementsImplementa una o varias interfaces.
instanceofComprueba compatibilidad del objeto con un tipo; null devuelve false.
(Perro) animalCasting: convierte la referencia, no el objeto.
