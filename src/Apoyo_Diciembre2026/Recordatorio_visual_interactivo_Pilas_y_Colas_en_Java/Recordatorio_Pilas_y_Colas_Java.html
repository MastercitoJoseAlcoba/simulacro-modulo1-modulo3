Atención: en una pila vacía, pop() y peek() lanzan EmptyStackException. En una cola vacía, poll() y peek() retornan null; remove() y element() lanzan NoSuchElementException. Los ejercicios validan antes de consultar o extraer.
Si la letra pide procesar todos los elementos, usá while (!estructura.isEmpty()). El return va después del ciclo, salvo que se busque finalizar de inmediato.
