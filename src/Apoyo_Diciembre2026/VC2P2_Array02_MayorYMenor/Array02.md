### Pregunta 1
En este ejercicio deberás trabajar con arreglos (arrays) y recorrer sus elementos para identificar valores especificos.
El objetivo es implementar métodos que permitan encontrar el valor máximo y el valor mínimo dentro de un array de números enteros.

### requisitos:
* Crear una clase llamada EncontrarMayorYMenorArray
* Implementar dos métodos estáticos:
* `encontrarMayor(int[] array)` - devuelve el valor máximo dentro del array
* `encontrarMenor(int[] array)` - devuelve el valor mínimo dentro del array

### Firmas de los métodos:
* public static int encontrarMayor(int[] array)
* public static int encontrarMenor(int[] array)
