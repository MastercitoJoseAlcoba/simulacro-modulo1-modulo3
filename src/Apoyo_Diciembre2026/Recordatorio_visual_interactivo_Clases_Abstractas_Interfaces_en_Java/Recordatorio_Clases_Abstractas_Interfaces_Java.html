Clases abstractas e interfaces, paso a paso

Entendé cómo compartir estado, definir contratos y combinar ambos conceptos.

1. Recordatorio visual

Clase abstracta

abstract class Figura

No se instancia directamente. Puede tener atributos de instancia, constructores y métodos abstractos o concretos. Una clase solo puede extender una clase padre directa.
Interfaz

interface Recargable

Define un contrato. No tiene constructores ni atributos de instancia. Puede declarar constantes y métodos abstractos, default, static y private. Una clase puede implementar varias interfaces.

5. Métodos y palabras clave
JavaInterpretación
abstract classClase que no se instancia directamente.
abstractMétodo sin cuerpo; puede declararse en una clase abstracta.
extendsHereda de una clase; una interfaz también puede extender interfaces.
super(...)Invoca un constructor del padre.
interfaceDeclara una interfaz.
implementsImplementa una o varias interfaces.
@OverrideComprueba la sobrescritura o implementación.
defaultMétodo de instancia de interfaz con implementación predeterminada.
public static finalLos campos de interfaz son constantes implícitamente.
newInstancia una clase concreta, no una clase abstracta o interfaz directamente.
