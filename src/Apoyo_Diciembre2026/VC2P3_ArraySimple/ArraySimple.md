# Ejercicio — Recorrer un array en Java

Implementa un método llamado `mostrarArray` que reciba un array de enteros (`int[]`).

## Tu tarea

1. Recorre el array con un `for`, desde la primera posición hasta la última.
2. Muestra cada número en una línea distinta.
3. En él `main`, crea un array de enteros y pásaselo al método.

El método debe ser `static` y tener tipo de retorno `void`, porque su tarea es imprimir los valores.

## Ejemplo

Para el array `{4, -2, 9, 1}`, la salida esperada es

```text
4
-2
9
1
```
