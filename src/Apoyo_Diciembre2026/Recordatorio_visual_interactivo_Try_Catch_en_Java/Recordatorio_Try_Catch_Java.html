6. Recordatorio FEIP
try: ejecuta instrucciones que podrían lanzar una excepción.
catch: captura una excepción compatible. Si se lanza una excepción, el resto del try se omite.
finally: normalmente se ejecuta tanto si hay una excepción como si no; incluso si esta se propaga. No es una garantía ante la terminación abrupta de la JVM.
Después de un catch que termina normalmente, continúa la instrucción posterior al bloque completo.
El navegador simula los ejemplos; no ejecuta un compilador Java.
