Animal a = new Perro();

Tipo real: Perro

a instanceof Perro → true
Animal a = new Gato();

Tipo declarado: Animal
Tipo real: Gato

a instanceof Perro → false

null instanceof Perro siempre es false. instanceof es una palabra reservada en minúsculas.
