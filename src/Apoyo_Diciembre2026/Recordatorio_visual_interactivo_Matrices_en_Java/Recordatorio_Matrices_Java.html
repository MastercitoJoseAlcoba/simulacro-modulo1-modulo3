Los métodos de este archivo suponen una matriz rectangular, no nula y no vacía, con al menos una columna. Para el punto silla se exige mínimo único en su fila y máximo en su columna (se permiten empates de máximo). Se devuelve el primer punto encontrado en orden de filas. En caso de no existir, se devuelve un array vacío.
