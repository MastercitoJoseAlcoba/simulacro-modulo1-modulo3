# Ejercicio — Invertir un array y duplicar los números pares

Implementa el método `invertirYDuplicarPares`, que recibe un array de enteros (`int[]`) y devuelve un nuevo array.

## Tu tarea

1. Crea un array nuevo del mismo tamaño que el original.
2. Recorre el array original con un `for`, desde el último elemento hasta el primero.
3. Si el número es par, multiplícalo por `2`. Si es impar, déjalo tal cual.
4. Guarda cada valor en el nuevo array, empezando desde la posición `0`.
5. Devuelve el nuevo array al terminar el recorrido.

## Ejemplo

```text
Entrada: [3, 4, 7, 2]
Salida:  [4, 7, 8, 3]
```
