Reglas rápidas para FEIP

arreglo.length - 1 - i: leemos desde el final mientras i avanza.

for (int i = arreglo.length - 1; i >= 0; i--): recorremos directamente desde el final.

En búsquedas, el return dentro del if termina el método. Si construimos un array completo, lo retornamos fuera del for.
