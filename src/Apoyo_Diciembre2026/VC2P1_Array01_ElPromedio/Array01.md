### Pregunta 1

Objetivo: Recorrer un array, filtrar valores según una condición (números pares) y cálcular un promedio.

Se cuenta con:
* Un método a implementar llamado: calcularPromedioPares(int[] array)
* Un array de números enteros que será utilizado como entrada.

### Tu tarea: implementar el método calcularPromedioPares para que:
* Recorra el array
* Identifique cuáles son los números pares
* Sume únicamente los números pares
* Cuente cuántos números pares hay
* Calcule y devuelva el promedio como un número decimal.

### Importante
* El método debe ser static
* No se debe implementar el método main
* No se deben pedir datos por teclado
* Si el array no contiene números pares, el método debe devolver 0
