### Clase de Utilidad para ordenamiento de burbuja

* Crea una clase de utilidad llamada Ordenamiento que contenga un método estático para implementar el algoritmo de 
ordenamiento de burbuja.
* El método debe recibir un arreglo de enteros y ordenarlo de manera ascendente.

### Programa Principal
* El programa principal (main), crea un arreglo de enteros desordenado y utilice el método de la clase Ordenamiento para 
ordenarlo.
* Muestra el arreglo antes y después del proceso de ordenamiento.

### Clase de Utilidad para Búsqueda
* Crea otra clase de utilidad llamada Búsqueda que contenga un método estático para implementar el algoritmo de búsqueda binaria.
* El método debe recibir un arreglo ordenado de enteros y un valor a buscar, y devolver la posición del valor o, -1 si no se encuentra.
