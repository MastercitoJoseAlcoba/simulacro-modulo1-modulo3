5. Conceptos clave
try intenta ejecutar instrucciones; catch captura una excepción compatible.
Primero se evalúa vector[1]; su valor se utiliza como índice externo.
Una excepción capturada en el primer bloque no impide ejecutar el segundo. Pero si vector == null, el primer catch no captura esa NullPointerException y el método termina abruptamente.
Un String vacío devuelve 0; un String null no permite invocar length().
Simulación del algoritmo original. No hay un catch genérico añadido ni ejecución de Java en el navegador.
