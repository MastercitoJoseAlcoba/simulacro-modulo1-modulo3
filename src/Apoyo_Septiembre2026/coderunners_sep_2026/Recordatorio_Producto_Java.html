this() llama a otro constructor de la misma clase. En estos constructores se ejecuta primero.
this.nombre = nombre; distingue el atributo del parámetro. trim() se usa para validar, pero se guarda el texto original, sin recortarlo.
&& evalúa de izquierda a derecha; si la primera condición es falsa, no evalúa la segunda. Así se evita llamar a trim() sobre null.
void no retorna un valor; String e int sí. mostrar() imprime tres líneas.
