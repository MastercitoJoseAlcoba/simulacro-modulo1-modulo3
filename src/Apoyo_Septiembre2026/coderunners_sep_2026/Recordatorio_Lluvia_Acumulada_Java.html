5. Qué recordar para FEIP
registros.length = filas; registros[0].length = columnas.
for exterior con j: selecciona la columna. for interior con i: recorre sus filas.
int suma = 0; dentro del primer for, antes del segundo, reinicia el acumulador para cada columna. acumulados[j] = suma; fuera del for interior guarda el total.
Complejidad temporal O(filas × columnas); espacio adicional O(columnas) para el vector. El método original supone una matriz no nula, con al menos una fila, rectangular y con filas no nulas. La interfaz exige al menos una columna. La simulación reproduce el desbordamiento de int de Java.
